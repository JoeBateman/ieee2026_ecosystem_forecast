
# IEEE Big Data 2026: Ecosystem Forecast

My development towards IEEE big data challenge 6.


# Dataset

40 years of data - 0.5 $^\circ$ spatial resolution, 54152 sites distributed across the globe. 

Targets are 6 ecosystem carbon variables. 
# Targets

1.	**Vegetation height**	Canopy / forest height
2.	**Aboveground biomass (AGB)**	Carbon stored in living vegetation above ground
3.	Soil carbon	Carbon stored in soils
4.	**Leaf area index (LAI)**	Leaf area per unit ground area
5.	**Gross primary productivity (GPP)**	Total carbon fixed by photosynthesis
6.	**Net primary productivity (NPP)**	GPP minus plant respiration
7.	**Heterotrophic respiration (Rh)**	Carbon released by decomposition
